# 📦 Perspective Box Trainer

**Бесплатный онлайн-тренажёр перспективы для художников и иллюстраторов.**

Кубы и цилиндры в правильной перспективе, линии и эллипсы, рисование по памяти и по опорным граням — прямо в браузере, без установки и регистрации.

🔗 **[Открыть тренажёр](https://ggop445637.github.io/perspective-box-trainer/)**

---

## ✨ Режимы

| Режим | Что тренирует |
|---|---|
| **Практика** | Бесконечный генератор кубов и цилиндров в разных ракурсах. Смотрите на фигуру и рисуйте её на бумаге или планшете. Новая фигура — по таймеру или по `Space`. Можно листать назад/вперёд по уже показанным ракурсам. |
| **Память** | Фигура показывается несколько секунд и исчезает. Нарисуйте её по памяти прямо на экране и сравните с эталоном — тренажёр посчитает точность. |
| **Линии** | Обводка пунктирных линий и эллипсов одним движением: проверка и следующий образец появляются сразу. Настраиваются изгибы, резкость углов, поворот, размер и форма эллипса. |
| **Призрак** | Часть фигуры дана сплошной опорой (видимые грани), остальное — пунктиром, который скоро исчезнет. Дорисуйте фигуру целиком. |

## 🧰 Возможности

- **Точки схода** — по кнопке показывает реальные точки схода и линии построения для текущей проекции. Количество точек (1/2/3) зависит от ракурса.
- **Сложность ракурса**: простой, угловой, динамика. До 3 объектов в сцене с общей или разной перспективой.
- **Свободное вращение камеры** мышью или пальцем, зум колесом или щипком, двойной клик — сброс.
- **Таймеры**: настраиваемый интервал автосмены (1–3600 с), время показа, авто-проверка.
- **Оценка точности** с допуском на дрожание руки: аккуратная обводка даёт ~100%, неточные и лишние штрихи снижают оценку.
- **Статистика**: серия дней, уровни, итоги дня, время тренировки, разбивка по режимам, экспорт в JSON.
- **Сетка** (клетка, изометрия, перспектива), своя палитра, светлая и тёмная тема.
- **Стилус**: поддержка силы нажатия и сглаживание штриха.
- Все настройки и статистика сохраняются в браузере.
- Русский и английский интерфейс, адаптация под телефоны и планшеты.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` / `N` | Новая фигура |
| `Enter` | Проверить рисунок |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / повторить штрих |
| `←` / `→` | Предыдущий / следующий ракурс (Практика) |
| `1` – `4` | Переключить режим |
| `T` | Пауза таймера |
| `R` / двойной клик | Сброс камеры |
| `H` | Скрыть / показать панель |
| `F` | Полный экран |
| `Esc` | Закрыть окно |

## 🚀 Запуск

Тренажёр — один самодостаточный файл `index.html`, без сборки, сервера и зависимостей. Достаточно открыть его в любом современном браузере.

```bash
git clone https://github.com/Ggop445637/perspective-box-trainer.git
cd perspective-box-trainer
# откройте index.html в браузере
```

### GitHub Pages

**Settings → Pages** → ветка `main`, папка `/ (root)`. Сайт будет доступен по адресу `https://<username>.github.io/perspective-box-trainer/`.

## 🛠️ Технологии

Чистые HTML, CSS и JavaScript, без фреймворков. Рендеринг через Canvas 2D с собственной перспективной проекцией (орбитальная камера, точки схода, скрытие невидимых рёбер) и поддержкой HiDPI-экранов. Настройки и статистика хранятся в `localStorage`.
